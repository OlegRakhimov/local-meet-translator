Instructions
How to use Local Meet Translator
A compact guide for preparation, live calls and interview practice.

        
01
Prepare once
Save the OpenAI key, check the candidate profile and build the Answer Library.
02
Connect the meeting
Start Bridge, connect the Meet/Zoom/Teams tab from the extension and start subtitles.
03
Run the interview
Keep subtitles and the assistant on top. Comments remain subtitles; real questions receive grounded answers.

        

          
Quick start for an English interview
  1. Open Settings and save your OpenAI API key.
  2. Open System and start Bridge.
  3. Open the meeting tab and connect it from the extension popup.
  4. On Dashboard choose en → ru and press Start subtitles.
  5. Open Interview Assistant and start a live session.

          
Interview Assistant
Automatic analysis reacts only to stable interview questions. Jokes and remarks remain in subtitles. Coding tasks receive an approach, plan, code, line-by-line explanation, complexity and speaking notes.

          
English expected and transcript protection
English expected first uses automatic recognition, retries suspicious text as English, rejects silent chunks before the network request, and blocks prompt echoes before translation. Dropped text never reaches subtitles, history, Coding Focus or the classifier.

          
Keywords and useful phrases
Each Answer Library question may contain a first sentence, English keywords with Russian translations, and reusable English phrases with Russian translations. Generate missing aids for one question or fill all incomplete questions. Reviewed answers are preserved.

          
Coding Focus and contextual replies
Remarks only enter the feed. Follow-up questions receive a separate answer. Recommendations are offered, direct requests and constraints revise the solution, corrections replace earlier inputs, and new tasks wait for confirmation.
          
Voice translation to the other participant
In Translation control select CABLE Input as output, select CABLE Output as the meeting microphone, confirm the checkbox and start outgoing voice translation.

          
Privacy and screen sharing
Share only the browser tab or meeting window. Keep content protection enabled. The desktop app does not store raw audio.

          
Main hotkeys
Ctrl+Shift+SShow or hide subtitlesCtrl+Shift+AShow or hide assistantCtrl+Shift+MMove assistant windowCtrl+Shift+FFreeze teleprompter

          
When something does not work
Check Bridge, reconnect the meeting tab, verify en as source language, use headphones and reset transient state in Diagnostics.
